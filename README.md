# Google Cloud Platform (GCP)

A hands-on learning repository documenting my journey with Google Cloud Platform (GCP).

## Learning Goals

- Understand cloud computing fundamentals and Google Cloud architecture
- Explore core GCP services for compute, storage, networking, and databases
- Practice IAM, security, and access management
- Build and deploy cloud-based applications
- Learn infrastructure automation, monitoring, and cost management

## Topics

| Area | Focus |
|---|---|
| Cloud Fundamentals | Projects, regions, zones, and resource hierarchy |
| Compute | Compute Engine, Cloud Run, and GKE |
| Storage & Databases | Cloud Storage and managed database services |
| Networking | VPC, subnets, firewall rules, and load balancing |
| Security | IAM, service accounts, and least-privilege access |
| Operations | Cloud Monitoring, Logging, and cost optimization |
